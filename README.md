# Hospital Management System
- A full-stack Hospital Management System developed using Java, Spring Boot, React, and MySQL. The application provides separate role-based dashboards and functionality for Admin, Doctor, Receptionist, and Patient users.

## Features
- Role-based authentication and authorization using JWT
- Patient self-registration
- Admin management of doctors, patients, receptionists, and departments
- Receptionist patient registration and patient management
- Receptionist appointment booking, viewing, rescheduling, and cancellation
- Doctor appointment management
- Doctor appointment confirmation and completion
- Doctor consultation remarks
- Patient appointment booking and cancellation
- Patient appointment details and history
- Profile viewing and editing
- Role-based dashboards
- Logout functionality
- Responsive user interface
- Public landing page with hospital information and services
